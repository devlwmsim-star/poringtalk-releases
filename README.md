# 포링톡 설치·업데이트

작업 표시줄 위를 돌아다니는 픽셀 펫과 함께 친구와 대화하는 Windows 앱이에요.

## 설치하기

1. [최신 릴리스](https://github.com/devlwmsim-star/poringtalk-releases/releases/latest)에서 **`PoringTalk-win-Setup.exe`** 를 받아요.
2. 받은 파일을 실행하면 바로 설치되고, 바탕화면과 시작 메뉴에 **포링톡** 바로가기가 생겨요.
   - PC에 **.NET 10 데스크톱 런타임**이 없으면 설치 전에 자동으로 받아 설치해요. 이때 **"이 앱이 디바이스를 변경하도록 허용하시겠어요?"** 창이 한 번 뜨면 **예**를 눌러 주세요. (Microsoft 공식 런타임이에요)
3. 포링톡을 켜고 **회원가입** → **새 방 만들기** 또는 친구에게 받은 **방 코드로 입장**하면 끝!

## 경고 창이 떠요 😮

포링톡은 아직 **디지털 서명이 없는 새 프로그램**이라, Windows와 브라우저가 "처음 보는 파일"이라고 알려 줘요.
바이러스라는 뜻이 아니에요. 아래처럼 넘어가면 돼요. **설치한 뒤의 자동 업데이트에서는 이 경고가 뜨지 않아요.**

**Edge에서 받을 때** — "일반적으로 다운로드되지 않습니다"

1. 다운로드 목록의 파일 옆 **`…`(추가 작업)** → **유지**
2. "이 앱이 디바이스를 손상시킬 수 있습니다" 창 → **자세히 표시** → **그래도 유지**

**Chrome에서 받을 때** — "일반적으로 다운로드되는 파일이 아닙니다"

- 다운로드 목록에서 **유지**(또는 **계속**)

**실행할 때** — 파란색 "Windows의 PC 보호" 창

- **추가 정보** → **실행**

## 업데이트

새 버전이 올라오면 앱이 **알아서 받아 둬요**. 포링이가 "새 버전 준비 완료"라고 알려 주면
펫을 오른쪽 클릭 → **업데이트하고 다시 시작**을 누르거나, 그냥 앱을 껐다 켜면 새 버전이에요.
지금 버전은 펫 오른쪽 클릭 메뉴 맨 아래에서 볼 수 있어요.

## 지우기

Windows **설정 → 앱 → 설치된 앱 → 포링톡 → 제거**
